# 论文可发表性与后续路线评估

## 2026-09-29：相对强化线性基线的独立确认

本轮证据有实质进展：嵌套训练内部调参后，两个 Burgers 划分的锁定候选，
在各500条新轨迹上分别降低主相对误差3.0779%和2.8752%，均通过预设1%
效果阈值及多重比较校正的配对区间标准。原划分采用稳定模态，独立划分
采用连续收缩；因此支持的是锁定选择流程，并非同一硬掩码跨划分必胜。

但方法创新证据仍不足：硬选择仍等于能量截断；连续收缩相对能量截断仅
改善0.2013%，区间跨零。Advection回退到线性映射，没有非线性收益主张。
这使“带明确适用边界的诊断及受控干预”论文更完整，但不是已证明的新
选择算法，也未与同数据预算FNO等强模型形成新的公平性能比较。

论文应突出可追溯的假设修正与确认链：旧确认失败、强化线性对照、锁定
新候选、两个划分确认收益、能量对照仍未被击败。若继续做方法创新，
优先验证对总场误差有实际贡献的模态筛选及拒绝机制，再补第二种非线性
PDE。三个确认集已消耗，不能用于新的调参后再称独立验证。详见
[本轮报告](INCREMENTAL_MODAL_V1.md)及[论文补充](../paper/FOLLOWUP_INCREMENTAL_MODAL_20260929.md)。

## 2026-09-28 损失与模态选择更新

归一化平方损失在两个互不重叠的 Burgers 训练划分上改善开发集主指标，
但它仍是逐样本相对 L2 的平方代理，而非完全一致的目标。
严格内部交叉验证选择前4/前2模态，与能量截断完全重合，因此不能声称
“可预测性选择”已优于能量排序。随机对照较差不足以支持这一创新结论。
这轮支持更扎实的诊断论文素材，尚未证实独立的新方法优势。

最终完成123条神经训练记录和48次岭回归网格拟合，其中25条是退化或重复
对照，不能算独立证据。第二PDE线性Advection上，归一化损失反而变差
（0.169283→0.175051），调好正则的纯岭回归达到0.015378。选择规则保留
全部16模态，无法区分线性欠修正与非线性需求。这一负对照比宣称跨PDE
通用改善更有信息量；它不是第二种非线性PDE上的成功验证。

除既有 POD 残差研究外，[Koike等，2026](https://arxiv.org/abs/2605.27756)
已研究稀疏神经网络的 POD 模态选择。具体目标和实现不同不等于广义首创。
下一版最值得检验的是：相对充分调参的线性修正，哪些模态仍存在稳定的
非线性增益，以及何时应拒绝修正。必须与同预算能量截断和连续收缩比较，
在锁定规则后使用新预留数据确认；这是后续假设，不能提前写作已实现贡献。
详见 [本轮协议与结果](OBJECTIVE_MODAL_V1.md)。下文保留各历史阶段判断。

## 2026-09-28 前序补充：残差修正及独立轨迹确认

已完成同基线性/非线性比较，以及冻结岭回归＋零初始化小残差、正则化和早停。
新500条轨迹在模型选择提交Git后才揭盲：主相对L2改善仅0.054%，配对区间跨0，
未达到预定成功标准；次要RMSE降低约2.14%。这加强了诊断证据的可信度，
但没有把项目升级为已验证的高性能新方法。不能把RMSE改为事后主指标。

POD＋学习残差已有直接文献：
[Demo等，2023](https://arxiv.org/abs/2302.12682)。下一步候选创新应聚焦
**用交叉拟合的模态可学习性决定修正/收缩/拒绝，而不只按POD能量或网络大小选择**。
先在开发数据核查损失与逐样本相对误差的一致性，再对上述规则与统一正则化、
随机模态及同预算调参做消融；最终需要新预留数据、独立训练划分及第二PDE。
这些是尚未实现的研究假设，仍需进一步文献对照，不能声称首创或一定能投稿。

## 结论先说

**有论文素材，但目前不宜直接包装成强方法论文。**
更合适的现阶段定位是可靠性 / 诊断 / 负结果案例研究，可整理为技术报告或
面向相关主题 workshop 的候选短文；能否被接收还取决于具体征稿范围和审稿。
若希望做成更有竞争力的完整研究论文，需要补齐独立验证和强对照，或把诊断
真正转化为可检验的干预选择方法。不能用“已跑 155 次”替代独立证据：其中
10 次是重复对照，且大量实验共享一个数据划分、父模型与少量种子。

当前确实站得住的发现是：**表示可拟合、训练可收敛、验证可泛化是不同问题；
在本协议中，诊断后的配对干预能改善前两项，却未普遍改善第三项。**
价值在可追溯的证据链和适用边界，不在声称第一次发现“过拟合”。

## 新颖性核查：哪些不能当新方法

| 已有工作 / 原始来源 | 与本项目的重叠 | 写作边界 |
|---|---|---|
| [Lee & Shin, 2023](https://arxiv.org/abs/2309.01020) | 两阶段 DeepONet 训练与正交化 | 不能把固定 trunk 后训练 branch、QR/SVD 本身写成首创；需要忠实方法对照。 |
| [Williams et al., 2024](https://arxiv.org/abs/2411.18459) | PI-DeepONet 基函数、奇异值与系数诊断 | 不能泛称首次分析 trunk 表示；监督实验也不能直接推翻其物理训练结论。 |
| [Lu et al., FAIR comparison](https://arxiv.org/abs/2111.05512) | POD-DeepONet、DeepONet/FNO 对照和归一化扩展 | 当前缺少重要的训练标签 POD 基线，不能只比较自己的弱配置。 |
| [ReZero, UAI 2021](https://proceedings.mlr.press/v161/bachlechner21a.html) | 零初始化残差思路 | 本项目输出层归零并非相同架构，但不能将零残差概念笼统称为原创。 |
| [SGDR, ICLR 2017](https://arxiv.org/abs/1608.03983) | 学习率调度 | 这里用 Adam 单段余弦，不是发明余弦衰减或重启方法。 |
| [Keskar et al., ICLR 2017](https://arxiv.org/abs/1609.04836) | 批量大小与泛化差距 | 训练更好而验证更差不新；没有测出因果机制就不能套用 sharpness 解释。 |

## 目前投稿最容易被质疑的地方

1. **外推不足**：公开数据只覆盖一个 PDE、参数、时间点和划分；五种子不是五个独立任务。
2. **基线偏弱**：多数 DeepONet 方案还不如预测输入空间均值。必须解释是任务设置、
   数据量、读出学习还是训练配置问题，而不是把所有失败都写成领域普遍失效。
3. **确认性不足**：实验按前轮结果逐步设计，测试集早期已被看过。应明确探索性，
   新的最终留出集必须先锁定，不能每轮查看后再修改方法。
4. **独立新意不足**：正交投影恒等式、零初始化与调度都不是新工具。
5. **物理主张不匹配**：新增强证据来自监督任务。若标题保留 physics-informed，
   就必须另有同样严谨的物理训练实验证据；当前版本先改为 DeepONet 诊断。
6. **因果归因过强的风险**：投影差距不是纯优化误差；相同更新步数也不等于同计算量。

## 最值得继续的方向：让诊断指导选择，而不仅解释结果

潜在研究问题：在固定总预算下，仅用训练 / 验证信息，能否提前判断应改善
表示、稳定优化、还是增加数据 / 正则化，并选到有效的干预？
这只是候选贡献，**当前未实现，也未证明比已有调参策略更好**。

### 第一步：补最便宜且能改变判断的证据

- 在原 1000 样本上做零初始化、batch32、恒定 / 余弦配对（两 trunk、五种子），
  区分 n=128 的欠覆盖与稳定收敛后的泛化问题。保留每一步预算和所有负结果。
- 同时补训练集 POD + 岭回归、POD + branch，以及忠实的两阶段训练参考。
  POD 只使用训练目标，正则化只由验证集选；按秩、样本数和预算匹配。
- 报告原始场与去均值残差指标、不同能量样本分层；不要仅为超过基线更换指标。
  可以用已有数据的更早预测时间作敏感性检查，但不能把另一个时间点当成第二 PDE。

**分流标准**：若强简单基线显著更好，优先研究输入到系数的学习；若同基下所有
方法都受限，才研究表示；若训练已经接近 oracle 而验证差，不再只追求更低训练损失。

### 第二步：把一个案例变成可复现现象

- 增加至少一种不同结构的公开 PDE，例如二维椭圆型或反应扩散问题，训练协议
  与监督 / 物理标签用途分别记录。具体数据与生成语义先核查再执行。
- 增加独立数据划分，保留训练种子配对；不把嵌套样本量或同模型多次检查当作
  独立统计单位。报告跨划分效果方向与失败案例。
- 新增最终留出轨迹只在方案冻结后使用一次。若据此改方案，该集合重新降为
  开发数据，并另留确认数据，不能仍称“未触碰测试集”。

### 第三步：再决定是否做方法创新

将早期投影误差、训练拟合差距和验证差距组成预先定义的干预选择规则，比较：
固定默认方案、随机选干预、同总预算验证集搜索。规则只能使用当时允许看到的
标签和指标，选干预的试验成本也要计入预算。跨 PDE 或留出配置评估选中方案
的效果与错误选择率，不能在同一组实验上拟合规则再报告“预测准确”。

只有诊断规则有样本外选择价值，才能把贡献从“案例分析”升级为“诊断驱动方法”。
若没有，则诚实聚焦可靠性案例与工具，不为凑新方法追加复杂损失或大模型。
