## 0. 一分钟版

对有守恒空间均值的 PDE，**常用的相对 L2 会把"只学会守恒量、完全没学到波动"的模型评价成可用**。本文把预测误差精确拆成"守恒均值"与"波动"两半，给出两个带证明的命题和一个零波动参照点；在完全相同的数据、划分与训练预算下量出：两个 DeepONet 的波动技能与"根本不预测波动"无法区分，而 FNO 显著为正。差距定位在输入到 trunk 系数的映射，而不是 trunk 的表示能力。现象在无共同轨迹的独立划分上复现，且放大 33 倍训练预算不改善。

**论文不是要给 DeepONet 的失败找原因，而是指出评价口径有一个结构性盲区，并给出一个能补上它的量。**

## 1. 问题：相对 L2 的结构性盲区

周期 Burgers 方程满足 $\frac{d}{dt}\int u\,dx = 0$，即空间均值守恒。实测三个数据划分上 `corr(mean(x), mean(y))` 全为 **1.000000**，平均绝对差约 $3\times 10^{-5}$（§3.4）。也就是说，目标场里有一个分量**不用求解方程、读输入就能拿到**。

这个"白送的分量"混在相对 L2 的分子和分母里。于是相对 L2 是一个**和**：它把"容易的那一半"和"真正要学的那一半"加在一起，无论这个和变大、变小还是不变，都看不出变化发生在哪一半。

一个具体例子（§5.2，Burgers ν=0.001，t=1.00）：

| 模型 | 相对 L2 | 逐样本波动 $R^2$ | 波动份额 |
|---|---:|---:|---:|
| 精确均值 + 零波动（参照） | 0.37577 | 0.0000 | 0.22002 |
| MLP DeepONet | 0.39357 | **−0.0042 ± 0.0072** | 0.2209 |
| Fourier DeepONet | 0.41231 | −0.0934 ± 0.0886 | 0.2406 |
| FNO | 0.22835 | **+0.6503 ± 0.0222** | 0.0769 |

MLP 的相对 L2 只比守恒律基线差一点，看着"能用"；但它的波动份额 0.2209 与零波动参照 0.2200 无法区分——**在波动上等于什么都没做**，剩余误差全在守恒均值那一半。

## 2. 方法：两个式子（工具，不是结论）

### 2.1 命题 1：精确正交分解（§3.1）

把场写成常向量与零均值残差之和：

$$y_j = \bar y_j \mathbf{1} + y_{c,j}, \qquad \mathbf{1}^{\top} y_{c,j} = 0$$

由毕达哥拉斯定理，对任意预测 `p_j` 与目标 `y_j`：

$$\|p_j - y_j\|^2 = N(\bar p_j - \bar y_j)^2 + \|p_{c,j} - y_{c,j}\|^2$$

两项正交（交叉项恒为 0），因此**均值份额与波动份额精确相加等于** $\mathbb{E}_j\,\mathrm{relL2}_j^2$。

> **关键分寸**：这是**恒等式，不是因果归因**。它对任意预测都成立，本身不能说明任何模型为什么失败。它的价值是让两半可以分别计算、精确可加。

### 2.2 命题 2：trunk 张成空间上的硬上界（§3.3）

DeepONet 的输出落在 $S = \mathrm{span}([\Phi, \mathbf{1}])$ 内（$\Phi$ 是训练得到的 trunk 基）。对任何这样的输出：

$$R^2_{\text{per-sample}} \le 1 - \frac{s_{\min}}{e}$$

其中 $s_{\min}$ 是目标波动落在 $S$ 之外的部分，$e$ 是逐样本波动能量。**$s_{\min}$ 由一个逐样本 oracle branch 达到，因此该上界对给定 trunk 是紧的**——不换 $\Phi$ 就无法提高。45 个训练好的 trunk 上，上界从不被违反（§5.7）。

> 注意：该命题**只对 DeepONet 类输出成立，FNO 不适用**。

### 2.3 为什么是这两块，而不是别的（§3.5）

论文里这件事实在散，读者反复问，现已补成 §3.5。三条理由：

1. **代数上是唯一不需要任何选择的正交二分**。$\mathbb{R}^N$ 里由数据本身给出、无需训练、无需选基、无需超参的正交分解只有"常向量 / 零均值补空间"这一个。POD 模态、低高频截断、按空间或按样本分，都**必须先选一个基或截断位置**，于是份额不再对任意预测精确可加、也不再与架构无关。常向量是一维、补空间是 $N-1$ 维，这也是最粗的划分；再细分就得引入本来要避免的基。
2. **物理上这一半恰好是"不用学就会的"**。守恒律使均值可从输入直接读出（§3.4），均值份额是白送的部分，波动份额才是要学的部分。**并且稿件验证过这个选择不是万能的**：稳态 Darcy 上 input–output 均值相关是 **−0.873**，没有守恒律联系，同一个 input-spatial-mean predictor 的相对 L2 变成 **3.6843**（§5.6.4）。稿件明说：这个基线的地位是**算子物理的属性**，不是指标或架构的属性；而零波动参照是纯代数的，不需要物理。
3. **只有这一半能给出自然的零点**。"精确均值 + 零波动"与"全零预测"都落在 $R^2 = 0$，于是"有技能 / 无技能"才有判据；命题 2 也依赖 $\mathbf{1} \in S$。换别的划分，就没有"什么都不学"的基准，gap 也无从定义。

**诚实边界**：命题 1 本质是任意正交投影下的分解，均值只是特例，可推广到其它守恒量或低/高频分裂。代价是要为每个 PDE 选投影、失去跨族可比性，且零点不再对应"什么都不学"。本项目里被相对 L2 掩盖的恰好就是守恒均值，所以选它才对准了问题。

## 3. 我们定义的量（以及容易误当成指标的量）

### 3.1 两个份额：是**误差账目**，不是评分

| 量 | 定义 |
|---|---|
| 均值份额 | $\mathbb{E}_j\, N(\bar p_j-\bar y_j)^2 / \|y_j\|^2$ |
| 波动份额 | $\mathbb{E}_j\, \|p_{c,j}-y_{c,j}\|^2 / \|y_j\|^2$ |

两者精确相加等于 $\mathbb{E}_j\,\mathrm{relL2}_j^2$，**不产生新信息**——只是把已有误差拆成两半。单看这两个数说不出模型好坏，必须和**参照点**比。

### 3.2 两个技能度量（§3.2）

都以**零波动预测器**为参照，故对均值不敏感，只度量波动技能：

- **能量加权** `fluctuation_r2` $= 1 - \sum_j\|p_{c,j}-y_{c,j}\|^2 / \sum_j\|y_{c,j}\|^2$，被高能量样本主导。
- **逐样本** `fluctuation_r2_per_sample` $= 1 - \text{波动份额}/e$，每个样本等权。**这是全文主指标。**

两者**必须同时报**，因为会给出相反符号：§5.4 在 20000 步时能量加权 **+0.2126**、逐样本 **−0.2470**。稿件不"选一个当真"，而把分歧当作信号——改善集中在高能量样本，典型样本反而变差。

### 3.3 不是指标的三个量

| 量 | 实际是什么 |
|---|---|
| 零波动参照 | **参照点**，定义"0 分"，没有它 $R^2$ 的零点没有意义 |
| $s_{\min}$ / 命题 2 上界 | **不需训练的天花板**，由 oracle branch 达到 |
| 技能临界时长（0.98 / 0.86 / 1.94） | **线性插值的结果量**，且依赖数据划分 |

### 3.4 与相对 L2 的关系：不是"更好"，是回答不同问题

| | 相对 L2 | 逐样本波动 $R^2$ |
|---|---|---|
| 回答 | 整体多准（含均值） | 除守恒量外还学到什么 |
| 盲区 | 容易的守恒分量把"波动没做"稀释掉 → **假阴性** | 对均值完全不敏感，均值稀烂的模型也能拿高分 → **假阳性** |

§3.2 原话：波动 $R^2$ *"is never a measure of total accuracy"*。§5.19 第 1 条原文是 *"Report the mean share, **not only** total relative L2"*——是"不只报"，不是"改报"。**两者都有盲区且不重叠，所以主张一起报。**

### 3.5 适用范围（§5.12）

逐样本 $R^2$ 对小范数样本敏感。稿件给出适用范围（目标范数变异系数约 <1、极差 <100 倍），并**主动排除** Darcy β=0.01（CV 2.43、极差 343 倍，$R^2$ 跑到 −1.9 ~ −87），说明那是量纲伪影加未收敛，不算证伪也不算确认。

## 4. 实验设计

### 4.1 总体结构

**受控对照 + 事后诊断 + 预注册**，不是"训几个模型比分数"。

| 层 | 做什么 | 关键脚本 |
|---|---|---|
| L0 数据锁定 | PDEBench 数据不进仓库（50 GB），每个 family 存 `protocol.json`（划分、种子、超参）+ 发布方校验码 | `download_pdebench.py`、`download_darus.py`、`download_advection.py` |
| L1 跑实验 | 匹配预算的监督对照：三个架构、5 个种子、固定 1500 步、同数据同划分同预算 | `run_public_benchmark.py` |
| L2 诊断复算 | **不重训**，从 `checkpoints/latest.pt` 重算两个份额与两个 $R^2$，并校验 closure 项到机器精度为 0 | `diagnose_fluctuation.py` |
| L3 专项分析 | 上界、阈值、分层台账、预算阶梯、FLOPs、PI 臂、split-2 不相交性与阈值重拟合 | `skill_bound.py`、`predict_skill_horizon.py`、`analyze_prediction_ledger.py`、`run_steps_ladder.py`、`run_physics_public.py`、`verify_split_disjointness.py`、`fit_rs2_thresholds.py` |
| L4 钉死 | 144 个测试断言"`summary.json` 里的数必须出现在 `main.md` 里"——数字一改就红 | `tests/test_paper_evidence.py`、`test_prediction_ledger.py` 等 |

每个 `result.json` 带 `identity.configuration` + `source_sha256` + `git_commit`，即**哪个字节的代码产生了哪个 run**可查。

### 4.2 从原始 run 到稿件数字

```
results/<family>/protocol.json                  ← 数据划分、种子、超参、字节校验
results/<family>/<arch>_s0…s4/result.json       ← 原始训练指标（train/val/test、train_seconds 等）
                                   selection = "last fixed-budget checkpoint"（不挑最好的）
                          checkpoints/latest.pt
        ↓ diagnose_fluctuation.py（从权重重算，不重训）
results/fluctuation_*/<family>.json             ← 两个份额、两个 R²、closure 项
        ↓ 汇总 5 seeds
results/fluctuation_*/summary.json
        ↓
paper/main.md 的表格
        ↓ tests/test_paper_evidence.py 断言数值一致
```

所以稿件里的分解类数字**不是训练日志里直接读出来的**，而是从存档权重复算的，重训也能验证用的是同一份 checkpoint。

### 4.3 预注册与双划分

23 份 `docs/*_V1.md` 协议事先写明端点、口径和判定规则。split 2 取自 split 1 全部 1400 个 id 的**补集**（seed 20261028），不相交是硬门禁（`verify_split_disjointness.py`），阈值在新划分上**重新拟合**而非沿用。

## 5. 主要结果（关键数字）

### 5.1 分离现象（§5.2）

见第 1 节表格。**FNO − MLP 的 gap = +0.6545** 是最稳定的单一数字，两个划分上都成立。

### 5.2 不是训练不足，且指标会假阳性（§5.3、§5.4）

| updates | MLP 相对 L2 | 能量加权 $R^2$ | 逐样本 $R^2$ |
|---:|---:|---:|---:|
| 1500 | 0.39357 | −0.0056 | −0.0042 |
| 5000 | 0.39729 | +0.0165 | −0.0640 |
| 20000 | 0.39311 | **+0.2126** | **−0.2470** |
| 50000 | 0.42075 | +0.1496 | −0.4157 |

训练量放大 33 倍，总误差基本持平（甚至略差），逐样本波动技能**更差**；§5.3 另重算 175 个干预 run（trunk 架构、白化、均值提升、零初始化、学习率调度、batch size、训练子集规模），**无一为正**。这两条把"没训够 / 没调好"排除掉；20000 步那一格同时说明**选错指标会把失败读成成功**。

### 5.3 视界依赖（§5.5）

七个预测时长 t = 0.10 / 0.25 / 0.50 / 0.75 / 1.00 / 1.50 / 2.00 上技能衰减，线性插值出**技能临界时长**（逐样本 $R^2$ 降到 0 的 t）：MLP ≈ 0.98、Fourier ≈ 0.86、FNO ≈ 1.94。短视界 t=0.10 时三者全正（+0.2199 / +0.6390 / +0.9859）。**线性对流上不衰减**，说明跟随的是非线性谱演化而非经过的时间；同一波动能量下三个架构的 $R^2$ 能差到 0.8，故不是分母变小造成的机械结果。

> 两个 "horizon" 别混：**预测时长 t** 是自变量（设置）；**技能临界时长**是插值出来的结果量，不是模型常数。它依赖划分：split 2 上 FNO 全程为正（t=2.00 时 +0.0972 ± 0.1689），**不穿零**，故该臂退出复现。

### 5.4 约束定位在 branch（§5.7）

| 设置 | trunk 上界 | 实际技能 | branch gap |
|---|---:|---:|---:|
| 线性对流 t=1.00（Fourier trunk） | +1.0000 | +0.9424 | **0.058** |
| Burgers t=2.00（**同一 trunk**） | +0.9845 | −0.3774 | **1.362** |

trunk 张成空间在所有视界上几乎能完美表示波动（上界 0.96–1.00），模型就是不产生它；换到平移问题，同一个 trunk 的 branch 几乎达到上界。**这把"约束在输入到系数的映射"变成可量化、自带对照的量。**

> ⚠️ **这是"损失落在哪一半"的定位，不是"branch 内部发生了什么"的因果证明。** gap 混合了 branch 容量、优化程度与只有 1000 条训练轨迹的数据量；固定 trunk 只换 branch 的干预实验未做，§6 列为首要待办。

### 5.5 物理信息训练（§5.11）

| 设置 | 相对 L2 | 均值份额 | 波动份额 |
|---|---:|---:|---:|
| oracle 输入均值 | 0.32623 | 0.0000 | 0.1875 |
| 监督 MLP | 0.36238 | 0.0334 | 0.1926 |
| PI MLP | 0.43613 | **0.1246** | **0.1875** |

PDE 残差收敛（loss 1e-1 → 6e-5），波动份额**精确等于 oracle**，均值份额涨约 3.7 倍。稿件原话：*"not worse at the fluctuation; it is worse at the conservation law"*。这是分解能定位缺陷、而不只是描述误差的最干净证据。

注意这一格也修正了一种常见概括：**L2 变差时，也可能把"没变的东西"藏起来**。

### 5.6 阈值规则与证伪（§5.15、§5.16）

只用训练目标算的先验波动能量阈值，在两个标量族上拟合、**此后从不重拟合**，对 55 个预注册的符号预测对了 **52** 个。分层后（55 个并非同等有信息量）：可区分设置 **27/30**、边界设置 **5/6**，"一律猜正"基线 **16/30**。

**明确标注为经验规律、不是定理**（§5.8 有状态说明），并且有已知失败：1D 可压缩 CFD **3/6**，2D 反应-扩散 **4/4**。

### 5.7 独立划分复现（§5.17）

无共同轨迹的 split 2 上重训 **315 runs / 21 families**，阈值重拟合：

| 端点 | split 1 | split 2 |
|---|---:|---:|
| MLP 逐样本 $R^2$ | −0.0042 ± 0.0072 | −0.0003 ± 0.0167 |
| FNO | +0.6503 ± 0.0222 | +0.6162 ± 0.0347 |
| **gap** | **+0.6545** | **+0.6165** |

阈值漂移 1.3% / 11.6%，在预声明的 25% 带内。主端点通过；FNO 的技能临界时长按上述原因退出。

## 6. 指标本身为什么可信（§3.5 新增）

这是读者最容易追问的一点：既然式子平凡、结论又是负的，这个量凭什么可信。稿件给的是**五类效度证据**，以及明确的"未证之事"。

| 类型 | 证据 |
|---|---|
| **构造效度** | 两份额精确可加，closure 项被测试钉到机器精度为 0；零波动参照使精确均值预测与全零预测都落在 0 分；命题 2 上界由 oracle 达到、45 个 trunk 从不违反；守恒律实测相关 1.000000 |
| **判别效度** | 不是只会给负分：FNO +0.6503、t=0.10 三者全正（最高 +0.9859）、平移 gap 0.058 对 Burgers 1.362；能区分有无守恒律（Darcy 相关 −0.873） |
| **定位效度** | PI 臂波动份额 0.1875 精确等于 oracle，均值份额涨四倍，与 PDE 残差收敛一致 |
| **预测效度** | 预注册 52/55、分层 27/30 与 5/6、基线 16/30，且 CFD 上明确失败——能前瞻预测，也有记录的证伪 |
| **可靠性与范围** | 独立划分 gap +0.6545 → +0.6165、阈值漂移 1.3%/11.6%；§5.12 给出适用范围并主动排除一个量纲伪影设置 |

**未证之事**（§3.5 末段）：没有外部"波动技能真值"可对照，故不能说它比相对 L2 更接近真值；没有形式化最优性或公理化刻画；没有下游任务验证（按此指标选模型是否改善后续决策）。以上主张只关于**可靠性、判别力与前瞻预测**，不涉及取代总误差作为精度度量。

## 7. 明确没有声称的

1. **不是因果机制**。命题 1 是恒等式、不是归因；branch 定位是数值定位，干预实验未做。
2. **不是新指标取代 L2**，也不主张"更准"。§5.19 是三条"同时报告什么"的建议。
3. **不是新近似理论**。两个命题是标准线性代数，稿件自己写明；贡献在于它们让什么变得可测。
4. **不是修复方法、不是新架构**。
5. **阈值规则不是定理**，有边界、有失败案例。
6. **5 个种子共用一个数据划分**，种子标准差反映初始化随机性，不是抽样不确定性；split 2 从另一维度补了独立性。
7. **技能临界时长依赖划分**，是线性插值量，t=2.00 的种子标准差 ±0.2357 使其有伪精度。

§7 另记录了审计过程中**主动撤回的两项主张**；判断可信度时建议先读那一节。

## 9. 常见疑问速答

**Q：论文到底证明了什么？**
A：只**证明**了两个数学命题（一个恒等式、一个紧上界），都是标准线性代数。其余结论是**可复现的经验事实**。两个式子是**尺子**，不是结论本身。

**Q：恒等式对任意预测都成立，推导又只有几行，写出来有什么用？**
A：平凡和有用不矛盾（全方差公式、ANOVA 平方和分解、Parseval 都是一行正交分解）。它的作用是**定义"失败"指什么、以及该报哪个数**：揭示常用的 input-spatial-mean baseline 其实就是守恒律预测器；让"相对 L2 会骗人"可量化；给出不需训练的天花板从而把失败拆成两类；并改变报告规范（§5.4 的 20000 步假阳性）。而且"DeepONet 在波动上没有正向结果"这句话本身依赖它给出的零点。

**Q：是不是证明了 DeepONet 不行／不行是因为波动没学好？**
A：都不是。论文甚至不是要说"DeepONet 差"——相对 L2 看着不算差。要说的是**换口径后它在波动上等于没学，而相对 L2 把这点盖住了**。也不是因果解释，分解只给出数值定位。

**Q：你们的指标比 L2 更好吗？**
A：不是。两者回答不同问题、盲区不重叠。波动 $R^2$ 对均值完全不敏感，单独用会假阳性；本身还有适用范围（§5.12）和两个 $R^2$ 互相矛盾的规模权衡。主张**一起报**。

**Q：我们提出的指标到底是啥？四个？**
A：**两个技能度量**（能量加权、逐样本等权，后者为主），加**两个误差份额**（均值、波动）。只有后两个中的技能度量是指标，份额是账目。另外零波动参照、$s_{\min}$/上界、技能临界时长都容易被误当成指标，其实分别是参照点、天花板、插值结果量。§1 用词是 *supplies*，不是 *proposes a new metric*。

**Q：为什么拆成这两块而不是别的？**
A：见 §2.3——唯一不需选基的正交二分；这一半恰好是守恒律白送的；只有它能给出自然的零点。且稿件用无守恒律的 Darcy 做了反例对照。**这不是唯一合法的分解**，可推广到任意正交投影，但要付出失去跨族可比性的代价。

**Q：是不是"L2 不变，别的东西变了，我们找到了那个东西"？**
A：直觉接近，但两处要修。①"L2 不变"只是 §5.4 预算阶梯这一组；主结果 §5.2 里 L2 是变的，PI 臂里 L2 还变差了却掩盖了波动没变。②不是"找到"了一个隐藏变量，而是把同一个**和**拆开——两份额精确相加等于 L2 的平方，一升一降而总和不变是代数必然。

**Q：哪些结果最能说明问题？**
A：三组带对照的对比，各排除一个替代解释：**上界 vs 实际**（§5.7，自带平移对照，排除"trunk 表示不了"）、**split 1 vs split 2**（§5.2/§5.17，排除划分偶然）、**少更新 vs 多更新**（§5.4，排除没训好）。不建议主打 52/55 或 FNO 的 1.94——前者有证伪、后者依赖划分。

**Q：至少该证明一下这个指标在某种程度上是好的吧？**
A：合理，且稿件已给五类证据（见第 6 节）。注意论文里**负的是 DeepONet，正的是这个量**：它不是一律给负分，能判别、能定位、能前瞻预测、跨划分稳定、有已知失效范围。**没有证明**的是"更接近某种真值"——这个领域没有波动技能的外部标签。

**Q：均值份额和波动份额帮助更好地评价模型？**
A：更准的说法：它们只是**账目**，不产生新信息；让账目变成判断的是**参照点**（零波动参照、oracle 上界、另一个 $R^2$ 加权）。三层是：拆分 → 参照 → 判断。而且它补的是盲区、不是提高精度，也不回答"为什么"。

**Q："视界"是什么意思？**
A：两个不同的 horizon。①**预测时长 t**，自变量，七个设置；②**技能临界时长**，逐样本 $R^2$ 降到 0 的那个 t，线性插值的结果。不是空间视野，更接近天气预报的"预报时效"。FNO 的 1.94 来自 t=1.50 时 +0.4051、t=2.00 时 −0.0586 之间拉直线找零点；是插值估计、依赖划分、有伪精度。

**Q：做了哪些实验支撑结论？**
A：三组对照（上界/实际、双划分、预算阶梯）加 175 个干预 run、45 个 trunk 的上界验证、33× 预算阶梯、七个视界、PI 臂、CFD 与 2D 族的跨系统检验、split 2 的 315 runs 复现。所有分解数字由存档 checkpoint **复算**（不重训），closure 项与稿件数值都被测试钉死。
